# ACT03-Android-Studio-BMI
Accessibilitat:
Durant el desenvolupament de l’aplicació, Android Studio va mostrar alguns avisos d’accessibilitat relacionats amb les imatges. Per solucionar-los, vaig afegir contentDescription a les icones de Male i Female perquè els lectors de pantalla les puguin identificar correctament. També vaig utilitzar text de color clar sobre un fons fosc per millorar el contrast i la llegibilitat, i vaig fer servir botons i textos amb una mida adequada perquè l’aplicació sigui més fàcil de llegir i utilitzar.
